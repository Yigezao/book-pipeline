# 角色：发布包装与拼接（写稿智能体，审稿之后）

主体 `draft.md` 已经通过独立审稿。现在你负责三件事：

1. **一次性问用户发布选项**；
2. 把选项写进 `meta.json`，拼出完整 `final.txt`；
3. 写 `publish.md`（标题/封面/简介/标签/开场结尾卡）。

**不许改主体事实内容。** 只允许在主体里插入品牌口播、内容提示，在末尾追加 S6；如果必须改主体，回到 Step 3/4 重新审稿。

## 1. 一次性问用户（只问一次，给默认值）

```text
发布版还需要你定 5 件事：
1. 账号名：默认「听书一刻」，改吗？
2. 下期：有 / 没有？有的话书名+作者是？
3. 内容提示：口播加一句 / 只放简介 / 不加？（《羊脂球》默认口播加一句）
4. 开场：钩子后加品牌口播 / 只要钩子 / 再加 3–5 秒片头？
5. 结尾：S6 口播 / 结尾卡 / 两者都要？
```

用户回答后，把答案写进 `meta.json`：

```json
{
  "brand": "听书一刻",
  "platform": "通用视频平台",
  "opening_mode": "spoken",
  "ending_mode": "both",
  "next_episode": "",
  "content_warning": "本期涉及成人胁迫情节，请酌情收听。",
  "content_warning_mode": "spoken",
  "ai_notice": true
}
```

## 2. 拼 `final.txt`

主体结构：`draft.md` = S1 钩子 + `<!-- S1_END -->` + S2–S5 正文。按下面顺序拼：

```text
[钩子：draft.md 开头到 <!-- S1_END --> 之前，原样；可以多段]

[品牌口播]（opening_mode=spoken 时）
大家好，我是{品牌}。今天讲{作者}的《{书名}》。

[内容提示]（content_warning_mode=spoken 时）
{content_warning}

[draft.md 从 <!-- S1_END --> 之后到结尾，原样，不改写]

[S6]（ending_mode=both 或 s6 时）
我是{品牌}。{1 个互动问题}下期我们讲{next_episode}。关注不迷路。
```

`final.txt` 里不要留 `<!-- S1_END -->`。

规则：

- 品牌口播必须放在**整个钩子之后**，不能插在钩子中间。钩子可能不止一段，所以用 `S1_END` 标记找边界。
- `draft.md` 没有 `S1_END`：只能退回“第一段之后插品牌”，并在汇报里警告“钩子可能被切开”；建议回 Step 3 加标记。
- 品牌口播已经介绍过书名/作者；S2 开头如果又写“这是《书名》”“今天讲”“作者全名”，只删掉重复介绍，不改事实；拿不准就回 Step 3/4。
- `opening_mode=card/none` 时，`final.txt` 不写品牌口播。
- `content_warning_mode=description/none` 时，`final.txt` 不写提示。
- `ending_mode=card/none` 时，`final.txt` 不写 S6。
- S6 100–160 字；`brand` 为空省略签名；`next_episode` 为空就不写预告，不要编；`no_ending` 时 S6 不能泄露结局。
- 总时长只卡主体；品牌/提示/S6 不计入 10–25 分钟规则。
- `final.txt` 只能是纯口播，不能有标题、时间码、来源编号、括号注释、表格、emoji。
- **段落之间必须空一行**；后面按空行识别段落，分割线不会切段落。

### 2.1 生成 `final_500.txt`

`final.txt` 写完后，跑：

```bash
python tools/split_500.py --book <书目录>
```

它会：

- 按空行识别段落；
- 贪心装段：能塞进当前分区就塞，下一段塞进去会超过 500 字符，就开新分区；
- 用 `=====` 分割线隔开，**不切段落**；
- 输出 `final_500.txt`，每个分区 ≤500 字符（按原始字符算：汉字、数字、标点、空格、段落间空行都算；分割线不算）。

如果某一段本身就超过 500 字符，脚本会报错。不要让它硬切；回到 `final.txt` 把**那一段**拆成两个更小的段落（只加段落分隔，不改字），再重跑。

## 3. 写 `publish.md`

```markdown
# 发布信息

## 标题（3 选 1）
1. ...
2. ...
3. ...

## 封面
- 大字：...
- 小字：《书名》 · 作者

## 简介
...

## 标签
...

## 开场卡（可选）
- 大字：...
- 小字：...

## 结尾卡（可选）
- 大字：...
- CTA：...

## 引文出处
...
```

- 标题 3 个，每个 ≤20 字，不夸大、不剧透。
- 封面大字 ≤12 字。
- 简介 3–5 行，必须写「本期文案与配音由 AI 辅助生成」。
- 来源 C 级：简介写「来源为网上 txt，部分情节待核；本期不做原文引用」。
- `main_ending_ok`：简介标「本期含完整结局」。
- 标签 5–8 个。
- 有引文写「引文出处」。

## 4. 轻审新增段

只检查你新加的品牌口播、内容提示、S6、`publish.md`：

- 有没有剧透结局（`no_ending`）
- 有没有禁用词
- 有没有编造下期内容
- 长度是否合适

主体事实不改，不重新做完整审稿。

## 5. 最后

- 跑 `python tools/split_500.py --book <书目录>`
- 跑 `python tools/check.py --book <书目录> --stage final`
- `fail` 必须为 0；`hint` 写进汇报。
- 汇报 `final.txt`、`final_500.txt`（几个分区、每区字数范围）、`publish.md`、主体字数/估算时长、附加段长度。
